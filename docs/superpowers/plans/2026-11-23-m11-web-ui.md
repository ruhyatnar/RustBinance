# M11 Web UI (`web-ui`) + `bot-ipc` Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the safety-first local SvelteKit 2 + Svelte 5 web dashboard (`web-ui`) per §11.1–§11.3 & §11.5, plus the 4 `bot-ipc`/CI compatibility fixes approved in the design doc.

**Architecture:** A single-page static app (`adapter-static`, fallback `index.html`) driven by a Svelte 5 runes store (`stream.svelte.ts`) connected to `bot-ipc`'s loopback HTTP + WebSocket gateway via first-message authentication. Monetary and risk decimals are formatted purely from server strings without `parseFloat`, read-only mode is enforced by default via `GET /api/v1/health` `auth_scope` plus an explicit UI unlock toggle, and destructive actions require a 1.5s hold-to-confirm gesture with a 10s server confirmation nonce.

**Tech Stack:** Rust (`bot-ipc`), SvelteKit 2, Svelte 5 (runes), TypeScript (strict), Tailwind CSS v4, `lightweight-charts`, Vitest + `@testing-library/svelte` + `jsdom`.

**Spec:** [2026-11-23-m11-web-ui-design.md](file:///home/antigravity/ruhyatnar/RustBinance/docs/superpowers/specs/2026-11-23-m11-web-ui-design.md), [11-ui.md](file:///home/antigravity/ruhyatnar/RustBinance/docs/spec/11-ui.md), [10-ipc.md](file:///home/antigravity/ruhyatnar/RustBinance/docs/spec/10-ipc.md), [M11-web-ui.md](file:///home/antigravity/ruhyatnar/RustBinance/docs/milestones/M11-web-ui.md).

## Global Constraints
- Default mode is **read-only**; unauthenticated users see zero data and zero actions.
- Tokens live only in memory / `sessionStorage` (never `localStorage`, never URL query strings).
- No trading/PnL math in UI; all precision decimal displays formatted from strings without `parseFloat`.
- No single-key shortcut for Panic; destructive actions require 1.5s hold + 10s server `confirm_nonce`.
- Every displayed position, order, signal, and market tick shows its `venue`.
- Color is never the sole carrier of meaning (icons ▲/▼ + explicit labels).
- `scripts/verify.sh` must pass completely (`rustfmt`, `clippy -D warnings`, `cargo test --workspace`, `cargo deny`, `web-ui` `npm ci && npm run check && npm test && npm run build`, secret scan).
- Out of scope: Venue Switcher (M16), PWA/public internet access.

## Review Focus
1. **Huge/high-precision decimal strings** (e.g. `"0.00000125"`, `"123456789012345.12345678"`, `"-0.00"`) — `formatDecimalString` must never lose precision via `parseFloat` or emit `"-0.00"`.
2. **WebSocket `seq` gap & reconnect race** — missing sequence numbers must trigger `{ type: "request_snapshot", payload: {} }`; duplicate/stale reconnect sockets must be cleaned up on disconnect/logout.
3. **Token privilege downgrade & logout cleanup** — switching from a `full` token to a `readonly` token (or logging out) must immediately clear cached snapshot/events, reset `controlsUnlocked = false`, and purge `sessionStorage`.
4. **Early release or pointer-leave during `HoldToConfirm`** — releasing before 1,500 ms must abort without calling `request_confirm` or `panic_flatten`, and a single keypress must never fire Panic.
5. **Dual error payload shapes from `bot-ipc`** — `401`/`403`/`429` (`HttpErrorResponse`) and `400`/`501` command rejections (`CommandResultPayload`) must both surface structured `ApiError { status, code, message }` to the operator.
