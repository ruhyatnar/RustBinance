## Runbook Singkat (Mode Testnet di CachyOS)
1. Build & install di host fisik CachyOS:
   ```bash
   ./scripts/build.sh
   sudo ./scripts/install-system.sh
   ```
2. Konfigurasi `/etc/binance-bot/config.toml` tetap `mode = "paper"` atau arahkan ke endpoint **Spot Testnet** dengan API key khusus testnet (tanpa akun live).
3. Jalankan daemon dan pantau selama ≥ 14 hari:
   ```bash
   sudo systemctl enable --now binance-botd.service
   ```
4. Hasilkan laporan otomatis dari SQLite journal:
   ```bash
   cargo run --release -p bot-backtest --bin bot-backtest -- \
     gate-report --db /var/lib/binance-bot/bot.sqlite --venue spot --gate G2 --out docs/gates/spot/G2.md
   ```
